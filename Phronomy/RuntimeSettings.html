Overview

This class is part of a private API. You should avoid using this class if possible, as it may be removed or be changed in the future.

Engine-facing values only. Application composition supplies the current settings object; this contract knows no Agent, adapter or tracer class.

def self.current
  settings = @provider&.call
  unless settings.is_a?(RuntimeSettings)
    raise ConfigurationError, "RuntimeSettings provider must return RuntimeSettings"
  end

  settings
end
