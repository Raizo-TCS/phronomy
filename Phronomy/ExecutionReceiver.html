Overview

This class is part of a private API. You should avoid using this class if possible, as it may be removed or be changed in the future.

Internal lifecycle/delivery contract for feature-owned execution state. A receiver has one serial owner supplied by composition, not an application callback SPI. Normal mutation and delivery run only on that owner. idle? runs under its lifecycle lock and must not acquire that lock again. shutdown runs on the failing owner or exclusively after it joins.

Direct Known Subclasses

Agent::ExecutionRegistry, WorkflowExecutionRegistry
