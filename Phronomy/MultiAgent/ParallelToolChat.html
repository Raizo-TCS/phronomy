Overview

This class is part of a private API. You should avoid using this class if possible, as it may be removed or be changed in the future.

RubyLLM::Chat subclass supporting concurrent direct Tool execution.

AgentInvocation installs on_tool_call_batch and intercepts the whole batch before this class dispatches anything. The direct-chat fallback dispatches the complete batch concurrently; process protection remains the responsibility of Runtime's bounded executors and queues.
