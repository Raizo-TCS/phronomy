Overview

Raised when an Application stream callback fails and stream_callback_error_policy is :fail_task.

This error represents delivery failure, not Agent, LLM, Tool, or FSM execution failure. The Agent result is retained in #result, and the original Application exception is available through both #original_error and Ruby's #cause chain.

def initialize(event_type:, original_error:, result: nil)
  @event_type = event_type
  @original_error = original_error
  @result = result

  super(
    "Stream callback failed while handling #{event_type.inspect}: " \
    "#{original_error.class}: #{original_error.message}"
  )
  set_backtrace(original_error.backtrace)
end
