Overview

Beta extension SPI for LLM call adapters.

External adapters implement #complete and #stream. The adapter or the underlying provider client owns transport timeout, retry, backoff, and rate-limit behavior. The framework supplies asynchronous execution outside this synchronous contract. Adapter implementers provide only these two methods and do not depend on the execution engine or its clients.

The current input to this SPI is the configured/materialized chat runtime object. Formalizing this SPI therefore does not imply a provider-neutral replacement for RubyLLMMaterializer.
