Overview

One immutable entry in the Agent's append-only Canonical Complete Execution Log.

Raw logical execution facts are never rewritten for Context selection or compaction. Derived Context artifacts must be appended separately and keep stable provenance back to their raw source records.

def self.from_h(hash)
  new(**ATTRIBUTES.to_h do |name|
    key = hash.key?(name.to_s) ? name.to_s : name
    [name, hash[key]]
  end)
end
