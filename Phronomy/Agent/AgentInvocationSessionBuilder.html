Overview

This class is part of a private API. You should avoid using this class if possible, as it may be removed or be changed in the future.

Builds FSMSession instances for AgentInvocation objects.

Blocking/provider work returns through explicit Agent-internal events. Entry actions start operations and return synchronously. Every LLM Call is prepared from a canonical Manifest and RuntimeProjection.
