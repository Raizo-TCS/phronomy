Overview

Represents a single evaluation sample with an input, an expected output, and optional freeform metadata.

Examples:

EvalCase.new(input: "What is 2+2?", expected: "4")
EvalCase.new(input: "Hello", expected: "Hi", metadata: { difficulty: :easy })
