Overview

Loads a plain-text file as a single document.

Examples:

loader = Phronomy::VectorStore::Loader::PlainTextLoader.new
docs   = loader.load("/path/to/file.txt")
# => [{ text: "...", metadata: { source: "/path/to/file.txt" } }]
